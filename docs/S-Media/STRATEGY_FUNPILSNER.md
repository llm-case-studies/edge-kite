
# Campaign Strategy: The "FunPilsner" Pivot

## The Persona: FunPilsner
**Vibe:** Craft Beer Enthusiast meets Cyber-Prepper.
**Philosophy:** "I like my beer cold, my code clean, and my data on *my* hard drive."
**Audience:** Home labbers, Makers, DIY Dads/Moms, Privacy advocates.

## The Core Narrative: "The Anti-Smart Home"
The tech industry wants you to buy a $3,000 smart fridge that needs a firmware update to make ice.
**EdgeKite** lets you glue a $5 sensor to a dumb fridge and get better data, offline, for free.

## Content Pillars

### 1. The "Brew-Master" (Homebrewing)
*   **Use Case:** Monitoring fermentation temperatures and Kegerator levels.
*   **Why EdgeKite:** If the cloud goes down, your beer shouldn't get warm.
*   **Theme:** Use the "Ranch" theme but call it "Brewery."

### 2. The "Garage Paranoid" (Security)
*   **Use Case:** "Did I leave the garage open?"
*   **Why EdgeKite:** Most smart openers send data to a cloud server. EdgeKite keeps it on your LAN.

### 3. The "Mobile Logger" (Cars/Vans)
*   **Use Case:** Vanlife or Daily Commute.
*   **Why EdgeKite:** Log data while driving (Offline). Burst-sync when you pull into the driveway.

### 4. The "BBQ Dad" (Cooking)
*   **Use Case:** Long-smoke brisket monitoring.
*   **Why EdgeKite:** WiFi reaches the yard, but the internet is spotty. Local LAN is rock solid.
