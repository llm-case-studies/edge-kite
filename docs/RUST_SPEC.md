
# EdgeKite Rule Engine Specification (v1.0)

## Overview

The EdgeKite Edge Agent (Rust) includes a lightweight **Pattern Detection Engine**. This engine analyzes the incoming stream of `EdgeEvents` in real-time, before they are persisted to SQLite.

Rules are defined in a JSON format that allows for high performance and low memory overhead.

## Rule Format

Rules are stored in a `patterns.json` file on the edge device (or in a `patterns` SQLite table).

```json
[
  {
    "id": "pt-001",
    "name": "Rapid Document Exfiltration",
    "severity": "critical",
    "enabled": true,
    "trigger": {
      "type": "threshold",
      "window_seconds": 60,
      "threshold": 20,
      "filter": {
        "category": "security",
        "type": "file_access"
      },
      "group_by": "user_id"
    }
  },
  {
    "id": "pt-002",
    "name": "After-Hours Login",
    "severity": "medium",
    "enabled": true,
    "trigger": {
      "type": "time_range",
      "start_time": "22:00",
      "end_time": "05:00",
      "filter": {
        "type": "login_success"
      }
    }
  }
]
```

## Trigger Types

### 1. Threshold Trigger
Alerts if `N` events match the filter within `window_seconds`.

*   **Use Case:** Brute force login attempts, bulk file downloads.
*   **Rust Implementation:** maintain a `VecDeque<(Timestamp, Key)>` in memory. Prune events older than `window_seconds`.

### 2. Time Range Trigger
Alerts if an event matching the filter occurs between `start_time` and `end_time`.

*   **Use Case:** Cleaning crew accessing servers, midnight logins.

### 3. Sequence Trigger (Advanced)
Alerts if Event A is followed by Event B within `window_seconds`.

*   **Use Case:** "USB Inserted" followed by "File Copy".

## Incident Creation

When a Rule triggers:
1.  An `Incident` object is created in memory.
2.  The `Incident` is flagged as `synced=false`.
3.  The Dashboard (UI) polls the `incidents` table to display the "Privacy Airlock" alert.

## AI Integration

The `PatternDef` format is designed to be easily generated by an LLM.
*   **Input:** "Create a rule to detect if someone deletes more than 5 files in 10 seconds."
*   **Output:** Valid JSON matching the schema above.
